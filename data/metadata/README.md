# Metadata

- `dataset_description.md`: scope, acquisition and label provenance.
- `file_naming_convention.md`: global participant codes and trial ordinals.
- `participants.csv`: participant codes and task availability, without personal initials.
- `schema.json`: common metadata and sample-column schema.
- `manifest.json`: 116 recordings, SHA-256 checksums and documented quality flags.

Private correspondence tables are not included in this directory.
