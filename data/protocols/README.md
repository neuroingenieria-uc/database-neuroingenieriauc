# Evaluation Protocols

This folder contains the released evaluation protocol PDFs used to acquire the dataset recordings.

The PDF contents are preserved from the source files. Repository filenames were translated to English and normalized to lowercase ASCII.

## Files

| File | Related task folder | Protocol |
| --- | --- | --- |
| `gait_10mwt_protocol.pdf` | `data/raw/gait` | 10 Meter Walk Test (`10MWT`) |
| `sit-to-stand_5sts_protocol.pdf` | `data/raw/sit-to-stand` | Five Times Sit-to-Stand Test (`5STS`) |
| `stair_ascent_descent_9sad_protocol.pdf` | `data/raw/stair_ascent`, `data/raw/stair_descent` | Nine Stairs Ascent and Descent Test (`9SAD`) |

## Source Files

These repository files were copied from the local Spanish protocol PDFs provided in the `Data Base/Protocolos` folder.
